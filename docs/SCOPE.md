# TrainingTracker — v1 scope

## Goal

Make it fast to log a workout set-by-set in the gym.

## In scope for v1

- Start a workout session
- Add exercises
- Log sets: reps and weight in kg
- Show previous performance for the same exercise
- Autosave the active session
- Finish a workout
- Show workout history
- Dark theme
- Local-first storage

## Out of scope for v1

- Charts
- Social features
- Export
- Goals
- Templates
- Supersets
- Web client
- Wearables
- Push notifications

## Decisions

- Play Store: no
- Testing: I will use the app myself
- Web client: later
- Weekly time: 10 hours
- v1 deadline: December 1, 2026
